# 선택적 로컬 충돌 분석

기본값은 비활성이다. 사용자가 자신의 기기에서 구동하는 OpenAI 호환 로컬 모델이 있을 때만 켠다. Growth Brain 서버나 상용 모델 API로 기억을 보내는 기능은 없다. 로컬 주소만으로 그 서비스가 외부에 재전송하지 않는다고 보장할 수 없으므로 직접 설치한 모델의 네트워크 동작을 확인해야 한다.

로컬 설정 파일 예시(인증키 없음):

```json
{"url":"http://127.0.0.1:11434/v1/chat/completions","model":"your-installed-local-model"}
```

사용자 터미널에서 `analysis-enable` → 설정 경로 → `LOCAL`로 동의한다. 현재 잠금 해제 세션에만 활성화되며 `analysis-stop` 또는 터미널 종료로 중지한다. 기기 밖 호스트·DNS 이름·리다이렉트·인증정보가 들어간 URL은 거부한다. 설치/다운로드/유료 모델 호출을 자동으로 수행하지 않는다.

관리 화면의 후보 검토에서 **선택적 로컬 충돌 분석**을 누르면 다음처럼 동작한다.

1. 동일 범위·동일 키의 현재 값과 다르거나, 작업 조건이 있거나, 제한된 지시어 규칙으로 모호한 후보만 분석한다. 명확한 후보는 모델 호출 없이 직접 검토한다. 이 규칙은 모든 의미적 충돌을 찾는다고 보장하지 않는다.
2. 후보 하나와 같은 범위에서 적용 조건이 겹치는 활성 기억 최대 10개만 제공한다. 다른 프로젝트, 폐기·대체·미승인된 다른 기억이나 전체 대화는 보내지 않는다. 16KB 프롬프트를 넘으면 내용을 자르지 않고 수동 검토로 돌린다.
3. 3.5초 제한, 응답 24KB 제한, 정형 JSON·완전한 응답 여부·허용된 교체 대상 ID를 검증한다. 시간 초과·오류·잘못된 대상·후보 변경 시 결과를 버리고 수동 검토 상태를 유지한다. 자동 재시도하지 않는다.
4. 결과는 미검증 조언이다. 사용자가 내용을 확인하여 수정란에서 새 후보로 저장하거나 직접 검토한다. 기존 기억과 후보 상태는 모델 호출로 바뀌지 않는다. AI/MCP 도구에는 분석 실행/활성화 API를 노출하지 않는다.

## 사용량 보호

요청 전에 금고에 보수적인 사용량을 예약한다. 요청 JSON의 UTF-8 바이트 수 + 출력/오버헤드 8,192 단위를 사용하며 실제 공급자 청구 토큰 수가 아니다. 실패해도 예약량을 돌려주지 않는다.

- 금고 전체와 프로젝트별 각각 분당 최대 20회.
- UTC 날짜 기준 프로젝트별 100,000단위, 금고 전체 500,000단위.
- 사용량은 금고의 암호문 상태에 포함되어 재시작·모델 재활성화로 초기화되지 않는다. 시계가 기록된 시각보다 뒤로 이동하면 거절한다. 오래된 백업을 사용자가 복원하면 해당 백업의 사용량으로 돌아갈 수 있다. 이는 유료 공급자 청구 한도를 보장하는 장치가 아니다.

내부 상태 v8은 사용량 장부를 추가한다. v1–v7 스키마를 먼저 검증하고 원본 암호문을 `pre-state-v8-*.enc`에 보존한 뒤 사용한다. envelope v1/v2는 유지한다.

검증은 실제 loopback HTTP 서버가 합성 모델 응답을 반환하는 방식이다. 게이트 0회 호출, 같은 범위 입력, 임의 교체 ID·정형 출력 위반·리다이렉트·타임아웃·취소·후보 변경·예산·재시작 보존을 확인했다. 실제 설치된 로컬 모델의 한국어 판단 품질·속도·비용이나 실제 사용자 실험 결과는 아니다.

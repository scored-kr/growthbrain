# 실제 제품 효과 검증 설계

2026-11-04 초안. 소유자: Growth Brain 제품 담당자. 시작/종료일 미정. 아직 실행하지 않았다.
기술 합격과 사용자 효용 실험을 구분한다. 공개 PM experiment-design/acceptance-criteria
스킬을 적용했으며, 개발 합성 corpus를 사용자 실험 결과로 취급하지 않는다.

## 가설과 배경

공통 선호도와 현재 프로젝트의 승인된 최신 결정을 새 AI 세션에서 제품 MCP로 조회하면,
반복해서 조건을 설명하는 사용자에게서 **조건을 만족한 첫 결과물까지 걸린 시간**이 줄어든다는 가설이다.
현재 실제 모델 호출 성공 증거는 없으므로 먼저 아래 기술 합격을 통과해야 한다.

## 선행 기술 합격

Given 사용자 기기의 Codex 로그인, 신뢰 검토된 훅, 명시 연결한 작업폴더/프로젝트,
합성 금고의 공통 한국어·프로젝트 전문 어조·최신 CTA·다른 프로젝트의 미끼 기억이 준비됨.
When 수집·후보 검토/승인 후 새 세션에서 “지난번 정한 조건대로 다음 작업을 진행해줘” 요청.
Then 사용자가 기억을 복사하지 않아도 실제 get_context 호출 기록과 결과물에서 한국어,
프로젝트 어조, 최신 CTA 적용을 확인하며, 현재 요청의 예외는 저장값보다 우선하고 미끼/이전 CTA는 없어야 한다.

`npm run test:codex`는 합성 브랜드/최신 CTA와 실제 호출 여부를 자동 검사한다. 어조/언어·
작업 품질은 사람이 사전 기준으로 추가 판정한다. `/hooks`의 신뢰·실제 수집은
`docs/agent-capture.md`의 별도 검증이며 해당 모델 검사를 통과했다고 자동 합격시키지 않는다.
우선 Codex 한 클라이언트의 전 과정을 완성한 후 Claude Code로 확장한다.

## 대조군과 처리군

- A: 새 세션, Growth Brain 연결 없음. 사용자가 평소 방법으로 조건을 다시 설명한다.
- B: 동일 계열 모델의 새 세션, 승인된 기억과 제품 MCP·동의한 자동 수집 연결.
- 미리 난도가 비슷한 서로 다른 작업 두 개를 준비하고 사용자별 AB/BA 순서를 무작위 배정한다.
  학습 효과를 줄이기 위해 같은 결과물을 재작성하는 과제는 쓰지 않는다. 화면 외형 변경은 없다.

## 지표

주지표는 시작 요청부터 **조건을 충족해 사용자가 수락한 첫 결과물까지의 분**이다.
보조지표는 조건 재설명 횟수와 검토/수정 시간이다. 도구 호출 성공률도 기술 진단용으로 별도 기록한다.
다른 프로젝트·미승인·사용 중지·대체된 기억 노출은 허용0건, 무동의 수집/평문 원격 저장도0건이다.
발견 시 해당 실험을 중지하고 기기 내 증거로 원인을 확인한다. 응답 지연/오류율도 두 군에서 함께 보고한다.

## 표본·기간

우선 동의한 목표 사용자10명의 탐색 파일럿으로 작업 난도·시간 분산·로그 수집 가능성을 확인한다.
이는 유의성을 주장할 표본이 아니다. 실제 baseline/유입량이 없어 확정 검정 표본과 종료일을 만들 수 없다.
가정 예시: paired log-time 차이의 표준화 효과0.5, 양측 alpha0.05, power0.8이면 정규 근사
`((1.96+0.84)/0.5)^2 ≈ 32`쌍이다. 소표본 t검정 보정 약34쌍, 누락15%를 고려하면 약40명이다.
이는 계획 예시이며 파일럿 분산과 최소 의미 효과(예: 시간20% 감소)를 사용해 **본 실험 전에** 다시 고정한다.
모집 가능 인원에 따라 정하되 최소2주, 같은 주차 패턴을 양쪽에 포함하고 중간 유의성으로 조기 종료하지 않는다.

## 대상·성공 판정

대상은 여러 AI세션에서 동일 프로젝트를 이어가는 콘텐츠/기획 실무자이며, 본인 기기와 합성 또는
별도 동의한 자료를 쓴다. 개발자 내부 테스트와 인증/정책 차단 세션은 효용 효과 계산에서 분리해 실패 건수로 보고한다.
AB/BA 각50%, 동일 모델/버전을 기록한다.

시간20% 이상 감소를 목표로 사전 고정한 신뢰구간·검정 기준을 충족하고 보호 지표가 모두 통과하면
효용을 지지한다. 보호 지표 위반은 실패다. 표본 부족·큰 불확실성은 결론 보류이며 성공으로 표시하지 않는다.
효용 실험 통과도 프로덕션 배포나 데이터 이전 승인을 대신하지 않는다.

## 위험·실행 노트

모델 버전/작업 난도/순서/승인 기억량이 결과에 영향을 주므로 고정하거나 기록한다. AI로 전달한
맥락은 해당 서비스가 읽을 수 있음을 사전 설명한다. 공통/프로젝트 원문·키는 분석 서버에 보내지 않는다.
익명화한 소요시간/판정/호출 횟수만 별도 동의 후 집계한다. 도구/결과 원문은 사용자 기기에 보존한다.
실험별 새 합성 금고를 써서 기존 금고를 초기화하지 않는다. 롤백은 실험 연결 중지이며 Git revert가
금고 데이터를 복원한다고 안내하지 않는다.

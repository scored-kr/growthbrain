# 2026-11-03 아키텍처 대조 및 구현 기준

검토 자료: 사용자 첨부 `writing-block.md` (사업 방향 및 MVP 전략), ign8t master_spec 1.0,
사용자의 [최신 명시 요구사항](requirements-2026-11-03.md).
첨부 문서의 일정·지표·타깃은 전략 제안으로 읽었으며, 보안·MCP 관련 명시 요구사항을 대체하지 않는다.

**결론: 제품의 큰 흐름은 일치한다. 기존 마스터 스펙의 구현 우선순위와 보안 구조는 수정해야 한다.**

| 항목 | 기존 마스터 스펙 | 적용 방향 |
| --- | --- | --- |
| 가치 | 독립 기억과 의사결정 연속성 | 유지. 저장량보다 피드백의 실제 결과 반영을 측정 |
| 초기 사용자 | 개발자·1인 빌더 우선 | 비개발직 AI 헤비유저, 콘텐츠 마케터를 우선 검증 후보로 설정 |
| 합격 시나리오 | 입력창 주입·복사 폴백 | 새 AI 세션이 실제 제품 MCP를 호출하고 조건을 반영한 결과물 생성 |
| 기억 범위 | 프로젝트 중심 | 공통 선호도 + 선택 프로젝트. 요청 > 프로젝트 > 공통 기본값 |
| 처리 위치 | 서버 평문 분류·Postgres 본문 검색 | 사용자 기기 해독·검색. 서버는 회원별 암호문 저장 |
| AI 저장 | commit_decision으로 확정 가능 | propose_memory로 후보만 기록, 로컬 사용자 검토로 승인 |
| 확장 역할 | 수집과 주입 중심 | 사이트별 동의·프로젝트 선택·중복 방지 수집. MCP 조회를 대체하지 않음 |
| 검증 목표 | 베타 30~50명, 단축률·리텐션 목표 | 11/13 프로토타입, 3~5명 테스트·5~10명 신청 시도. 효과는 아직 미검증 |

첨부의 '프로젝트 맥락 관리 2단계'는 고급 기능 확장으로 해석한다. 프로젝트 격리, 최신 결정,
출처와 변경 사유는 첫 엔진부터 포함한다. 암묵적 선호도 추론은 승인 전 후보로만 남긴다.

## 실행 구조

```text
사용자 로컬 터미널 ── 잠금 해제·기억 검토 ── 로컬 금고 프로세스
                                               │ 해독·검색
AI 클라이언트 ── stdio Growth Brain MCP ── 사용자 전용 Unix socket
                                               │
                                        인증 암호화 파일

후속: 동의한 사이트의 확장 수집 → 동일 로컬 기억 엔진
후속: Supabase Auth/RLS → 회원별 암호문 동기화 (기존 스키마 먼저 점검)
```

ign8t MCP는 개발 명세·보드용이며 위 제품 경로에 포함되지 않는다.
복구 키·비밀번호는 MCP 도구 인자나 응답에 넣지 않는다. MCP는 승인·잠금 해제 도구를 제공하지 않는다.
현재 복구 범위는 로컬 엔진과 제품 MCP 프로토콜이다. 사용자 기기 실검증, AI 클라이언트 세션,
Supabase 동기화, 확장, 최소 관리 화면을 완료했다고 보지 않는다.

## ign8t 반영

- 변경 제안 `d6c3a0d1-fdd3-4435-9d27-3f8c49175ef2`: 위 차이와 첨부 전략을 기록.
- 복구 작업 `1fcd946c-2c3c-4541-9d16-31a45e2a8f51`: 실행 가능한 로컬 기억 엔진·제품 MCP.
- 개인화 MVP 및 콘텐츠 피드백 베타 검증 지표 추가.
- MCP에는 기존 마스터 본문을 직접 편집하는 도구가 없다. 변경 제안은 검토 대기 상태이며,
  마스터 본문 자동 재생성·유료 Sparks 사용·환경 재게시를 수행하지 않았다.

# 일반 채팅의 기존 기록 가져오기

2026-11-05 사용자 결정: **초기 MVP는 ChatGPT와 Claude의 일반 웹 채팅 모두**다.
선호도 개인화가 최상위 가치이고 맥락 인계가 이를 이어 준다. Codex·Claude Code 성공을
일반 채팅 성공으로 대신하지 않는다. 이 챕터는 기존 기록 가져오기이며 실제 웹 AI 연결 완료는 아니다.

## 사용자 흐름

1. 사용자 기기에 금고·native host·확장을 준비하고 별도 로컬 터미널에서 금고를 연다.
2. ChatGPT는 설정 → 데이터 제어 → 내보내기, Claude는 설정 → 개인정보 → Export data를 사용한다.
3. 다운로드한 ZIP을 기기에서 풀고 확장 아이콘의 **기존 채팅 대화 가져오기**를 누른다.
4. 새 탭에서 서비스·프로젝트를 선택한다. 프로젝트가 없으면 이 화면에서 만들 수 있다.
5. `conversations.json` 또는 번호가 붙은 대화 JSON을 하나씩 선택한다. 목록에서 대화 하나를 골라
   발언자·시각·본문·제외 개수를 미리 본다. 파일 선택만으로 금고에 전송하거나 저장하지 않는다.
6. 선택한 프로젝트에 가져오기를 동의한다. Claude 파일에 현재 분기 정보가 없으면 그 한계를
   확인하는 별도 체크가 필요하다. 가져온 기억은 후보이며 자동 확정되지 않는다.
7. 확장 popup의 **기억 검토**에서 원래 서비스·대화명·시각을 보고 현재 유효한 후보만 승인한다.
   기존 조건을 교체하려면 대상을 명시한다. 사용 중지·대체된 기억은 자동으로 부활하지 않는다.

공식 안내: [ChatGPT 내보내기](https://help.openai.com/en/articles/7260999-exporting-your-chatgpt-history-and-data),
[ChatGPT 대화 JSON 파일](https://help.openai.com/en/articles/9106926-transfer-exported-conversations-between-chatgpt-accounts),
[Claude 내보내기](https://support.claude.com/en/articles/9450526-export-your-claude-data).
다운로드/계정 권한·관리 정책은 각 서비스가 결정한다. 기기 파일을 개발 클라우드에 올릴 필요가 없다.

## 지원 형식과 분기

| 서비스 | 읽는 구조 | 분기/본문 규칙 |
| --- | --- | --- |
| ChatGPT | 대화 배열, id 또는 conversation_id, title, mapping, current_node | current_node부터 parent를 따라 현재 분기만 선택. 사용자/assistant의 일반 text parts만 보존. 숨김·analysis·도구/첨부는 제외 |
| Claude | 대화 배열, uuid, name, chat_messages | current_leaf_message_uuid와 parent_message_uuid가 있으면 현재 분기를 검증. 둘 다 없는 평면 export는 **분기 미확인**으로 표시하고 별도 동의 |
| Claude 본문 | content의 type=text, 과거 형식의 text | content가 있으면 일반 text 블록만 읽고 thinking/tool_use/tool_result/첨부를 제외. 이를 text 필드의 대체 문자열로 덮어쓰지 않음 |

부모 정보가 일부만 있거나 현재 leaf가 없는 분기 구조, 순환·누락 연결·중복 메시지 ID는 거부한다.
가장 최근 시각을 보고 임의의 답변을 고르지 않는다. 평면 Claude 파일의 순서는 파일 순서이며
시간순/현재 분기라고 보장하지 않는다. 분기 미확인 표시를 암호문과 후보 사유·검토 화면에 보존한다.
ChatGPT message create_time과 Claude created_at을 UTC 시각으로 정규화하며, 시각이 없으면
미상으로 둔다. 본문은 잘라내거나 공백을 지우지 않는다. 텍스트 블록 사이에는 개행을 둔다.

공식 도움말은 export 경로를 설명하지만 내부 JSON 스키마의 영구 호환성을 보장하지 않는다.
Claude 형식은 [공개 뷰어 스키마](https://github.com/osteele/claude-chat-viewer/blob/main/src/schemas/chat.ts)
(검토 blob `14fa3a13f9295fb0d82de48bdf803fb9baf9d568`)와 대조했다. 해당 구현 코드는 복사하지 않았다.
현재 실제 사용자 export를 검증한 것은 아니며 합성 형식 fixture의 지원 범위다. 알 수 없는 형식은
성공처럼 처리하지 않는다. 계정 전체의 저장 선호·설정·프로젝트·파일을 이관하는 기능도 아니다.

## 저장·검토·중단 계약

- 선택한 대화만 확장 탭 → native messaging → 사용자 전용 IPC → 로컬 암호문으로 보낸다.
  브라우저 storage/서버/외부 모델에 원문·제목을 저장하지 않는다. 메모리상의 파일은 탭을 닫거나
  파일 선택을 지우면 참조를 해제한다. 원본 다운로드 파일은 사용자 기기에 남는다.
- 일회 가져오기는 사이트 자동 수집 동의를 켜지 않는다. 지정한 프로젝트에만 저장하며,
  사용자 발언의 기존 보수적 규칙 분류가 **프로젝트 후보**만 만든다. assistant 발언은 원문으로
  보관하지만 선호·사실 후보로 자동 승격하지 않는다. 공통 선호 등록은 별도의 명시 제안/승인이 필요하다.
- 같은 서비스·대화의 가져오기 대상은 한 프로젝트로 고정한다. 다른 프로젝트 선택으로 중복 배치하지 않는다.
  ChatGPT와 Claude의 우연히 같은 ID는 독립 출처다. 이름이나 파일 속 프로젝트 필드를 신뢰해 자동 배치하지 않는다.
- 가져오기 메시지 ID/본문 해시로 재시도를 중복 제외한다. 과거 수정본을 다시 가져와도 이전 후보를
  재생성하지 않는다. DOM 자동 수집과 export는 별도 출처 식별을 쓰므로 두 경로 사이의 내용상 중복까지
  제거하는 것은 아니다. 의미가 같은 다른 문장/다른 메시지도 자동 병합하지 않는다.
- 최대20메시지/60,000 UTF-8 bytes씩 보내며 각 묶음은 금고의 원자적 저장을 사용한다. 전체 파일에
  대한 하나의 트랜잭션은 아니다. 중단은 진행 중 묶음의 결과를 확인한 뒤 적용하고 이미 저장한 내용은 남는다.
  네트워크/연결 오류로 마지막 묶음의 결과를 모르면 완료로 표시하지 않는다. 사용자가 동일 파일/대화를
  다시 선택해 확인할 수 있다. 요청 도중 서비스·프로젝트·파일 변경은 잠그고 대상은 시작 시 고정한다.
- 가져오기/프로젝트 생성은 신뢰한 확장 import 페이지 전용 관리 경로다. content script와 popup의
  임의 import 요청을 거부하며 제품 MCP에는 해당 도구를 등록하지 않는다. 열린 금고를 같은 OS 사용자로
  실행되는 악성 프로그램에서 격리한다는 뜻은 아니다. 출처 파일의 진위를 암호학적으로 증명하지도 않는다.

파일20MiB, 대화당 분기 노드5,000개, 메시지12,000자, 금고 총 캡처5,000개/기억10,000개/16MiB
한도를 유지한다. 큰 메시지나 이미 잘린 Claude 메시지는 대화 가져오기를 거부하고 자동 절단하지 않는다.
ZIP/HTML/이미지/첨부·추론·도구 본문/자동 계정 스캔/대용량 스트리밍은 지원하지 않는다.
규칙이 놓친 선호나 비정형 판단 기준을 전부 추출했다고 주장하지 않는다.

## 데이터 버전과 검증

내부 상태 **v6**는 importSource(서비스·대화/메시지·제목·시각·분기)를 캡처에 추가한다.
v1~v5를 엄격하게 검증해 변환하고 기존 금고를 열 때 첫 쓰기 전 원본 암호문을
`pre-state-v6-<24자리 hex>.enc`로 보존한다. envelope v1/v2는 그대로이며 실제 사용자 금고를
개발 환경에서 열거나 변환하지 않았다. Git revert는 사용자 데이터를 되돌리지 않는다.
옛 코드가 필요하면 전환 전 백업과 당시 비밀번호/복구 파일로 새 경로에 복원한다.
로컬 delete-all은 관리 전환 백업도 지우며 사용자 export/복구 파일/원격/AI 사본은 별도다.

검사는 합성 자료로 파서·현재/미확인 분기·추론/도구 제외·출처·중복·프로젝트 격리·승인 전 조회 제외,
실제 native → IPC → 암호문 → 로컬 승인 → 별도 stdio MCP 조회, v5 백업/v6 복원 및 복구 파일 복원을
확인한다. Chromium 파일 선택·동의·프로젝트 생성·중단/재시도·오류 UI는 실제 브라우저+mock Chrome
transport 검사다. 980px/320px 화면과 XSS성 제목의 안전한 표시를 검사한다.

설치된 확장/사용자 export/로그인한 ChatGPT·Claude 일반 채팅의 실제 MCP 호출과 결과물은 아직
미검증이다. ChatGPT 공식 [연결 안내](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt)는
HTTPS 또는 지원 Secure MCP Tunnel 경로와 계정/워크스페이스 권한을 설명한다. 기존 로컬 stdio를
웹 채팅에 곧바로 연결할 수 있다고 가정하지 않는다. 사용자 기기에서 해독·검색하는 원칙을 지키는
양쪽 일반 채팅의 연결·실제 결과 검증은 후속 과제이며 수동 복사로 MVP 합격을 대체하지 않는다.

기존 채팅 대화 가져오기

ChatGPT는 설정 → 데이터 제어, Claude는 설정 → 개인정보에서 데이터를 내보낼 수 있습니다. 받은 ZIP을 기기에서 풀고, conversations.json 또는 번호가 붙은 대화 JSON을 하나씩 선택하세요.

파일은 이 기기에서 읽습니다. 가져오기에 동의하고 실행하기 전에는 금고에 보내지 않습니다. 가져온 내용은 로컬에서 암호화하며, 승인한 기억을 나중에 AI에 전달하면 해당 AI가 읽을 수 있습니다.

로컬 금고 연결 확인 중…

가져올 대화와 저장 대상

아직 선택한 대화가 없습니다.

이미지·첨부·도구·추론 내용은 가져오지 않습니다. 현재 분기 정보가 있으면 다른 답변 분기는 제외합니다. 과거 결정은 지금과 다를 수 있어 새 기억 후보만 만들고 자동 확정하지 않습니다. 공통 선호도로 자동 등록하지 않습니다.

가져온 후보는 확장 아이콘의 ‘기억 검토’에서 승인·기각하세요. 중단 전에 저장된 항목은 남습니다. 같은 파일의 같은 대화를 다시 가져오면 중복을 제외합니다. 이 기능이 새 채팅의 AI 연결까지 완료하는 것은 아닙니다.
